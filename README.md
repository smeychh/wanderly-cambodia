# Wanderly Cambodia

A responsive travel-booking landing page for a fictional Cambodia tour company. This is a front-end practice project built with HTML, CSS and vanilla JavaScript.

> **Demo project.** Wanderly Cambodia is not a real company. The name, prices, address, phone number and email on the site are made up.

**Live demo:** [https://smeychh.github.io/wanderly-cambodia/]

## Features

- Responsive layout from large desktop down to small phones (checked at 1280px, 1000px, 768px, 480px and 375px)
- Light and dark theme toggle that follows the device setting by default and remembers the visitor's choice
- Mobile menu with an accessible open/close button
- Search bar with a two-month date-range calendar
- Custom SVG icons, temple logo and favicon
- Keyboard-friendly: visible focus outlines, labelled form fields and image alt text

## Built with

- HTML5 and CSS3 (custom properties, Grid, Flexbox, media queries)
- Vanilla JavaScript
- [Litepicker](https://github.com/wakirin/Litepicker) for the date picker
- Google Fonts

## Run it locally

1. Open the project folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser.
